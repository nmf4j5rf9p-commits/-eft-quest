EFT PvE Quest Navigator — FINAL 1.0

목표
- PvE / Prestige 새 시작 기준으로 Lv.1부터 퀘스트 진행을 따라갈 수 있는 모바일 우선 PWA.
- 프로필 기본값을 입력한 뒤 완료 체크 중심으로 다음 퀘스트/추천 맵/레이드 준비를 안내.

최종 핵심
- Prestige 회차별 완료 상태 저장, 고정 프로필 저장 키와 구버전 자동 이전
- PvE 데이터: Tarkov.dev 정적 JSON 우선, TarkovTracker proxy 보조, 마지막 정상 캐시 fallback
- 한국어 번역 어댑터
- tarkov-data-overlay shared + modes.pve 적용
- overlay disabled task 제외
- objective ID별 patch와 objectivesAdd를 공식 구조에 맞춰 병합
- 선행퀘/레벨/상인 조건의 ready/locked/review 판정
- D등급 데이터는 추천에서 제외
- 맵별 퀘스트 묶기, 준비물/키/아이템/FIR 안내
- 레이드 목표 한 단계씩 완료 → 다음 목표 → 탈출 → 다음 추천 맵
- 멀티맵 목표와 전체 퀘스트 제출 가능 상태 분리
- 추천 점수의 후속퀘 중복 제거
- 좌표 → 검증 랜드마크 그래프 → 안전 fallback 순서의 동선 정렬
- 실제 활성 탈출구는 게임 내 확인하도록 보수적 안내
- Lv.1 자동 완주 검사: 엄격 / 구조 연결성 분리
- 품질 계기판, 교정 큐, 원인 추적, 보수적 자동교정, 회귀 방지
- 사용자 진행률과 제품 품질 점수 분리
- PWA 서비스워커 / 오프라인 앱 셸 / 진행 백업·복원

데이터 안전 원칙
- 확인되지 않은 조건은 '확인 필요'로 남김.
- 자동교정은 고유하게 확정 가능한 경우만 적용.
- 자동교정 후 품질이 악화되면 해당 배치를 거부.
- 지도 랜드마크 그래프는 정확한 보행 최단거리라고 주장하지 않음.
- 실제 레이드의 활성 탈출구는 게임 내 상태가 최종 기준.

설치
1. HTTPS로 호스팅된 index.html을 Safari에서 연다.
2. 공유 → 홈 화면에 추가.
3. 첫 실행 후 PMC 레벨/Prestige를 입력한다.
4. '지금 할 일' → 추천 맵 → 레이드 플래너 순서로 사용한다.

주의
- ZIP을 파일 앱에서 직접 여는 것만으로는 iPhone PWA/Service Worker가 완전하게 동작하지 않는다.
- 실제 홈 화면 설치/오프라인 기능에는 HTTPS 호스팅이 필요하다.
